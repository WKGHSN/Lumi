# 🌸 LumiBeauty — Онлайн-запис до салону краси

> Повнофункціональний веб-застосунок для онлайн-бронювання послуг краси з рольовою системою доступу.

## 🎯 Огляд проекту

**LumiBeauty** — преміальна платформа для запису до салону краси, розроблена як дипломний проект з увагою до UX/UI, архітектури та функціональності.

- **Мова:** Українська
- **Стек:** Next.js 14 + TypeScript + Tailwind CSS + Zustand
- **Дизайн:** Мінімалістичний, пастельна колірна палітра

---

## ✅ Реалізовані функції

### 🌐 Публічна частина
- **Головна сторінка** — Hero section, статистика, перелік послуг, команда, відгуки, CTA
- **Сторінка послуг** — Sidebar-навігація по категоріях, список послуг з цінами
- **Сторінка майстрів** — Картки майстрів з фото, рейтингом, фільтрами
- **Галерея робіт** — Masonry-grid з hover-ефектами, фільтрація по категоріях
- **Сторінка відгуків** — Рейтинг-підсумок, зірки, картки відгуків
- **Контакти** — Адреса, телефон, години роботи, OpenStreetMap

### 📅 Система бронювання (5 кроків)
1. **Обрати послугу** — категорії + конкретні процедури з цінами
2. **Обрати майстра** — фільтрація за спеціалізацією, рейтинг, досвід
3. **Обрати дату** — Повноцінний місячний календар (враховує робочі дні майстра)
4. **Обрати час** — Тайм-слоти (кожні 30 хв), зайняті слоти виділені
5. **Підтвердити** — Зведення запису, форма даних клієнта, угода

### 🔐 Авторизація (3 ролі)
- **Клієнт** — реєстрація / вхід / власний кабінет
- **Майстер** — вхід / кабінет з розкладом
- **Адміністратор** — вхід / повна адмін-панель

### 👤 Кабінет клієнта
- Статистика записів
- Список майбутніх записів + скасування
- Історія записів
- Редагування профілю

### ⚙️ Адмін-панель
- **Дашборд** — KPI, записи сьогодні, статистика по категоріях
- **Всі записи** — таблиця, пошук, підтвердження / завершення / скасування
- **Послуги** — список по категоріях, редагування (демо)
- **Майстри** — картки, редагування (демо)
- **Клієнти** — список, кількість записів, витрачено

### 📆 Кабінет майстра
- Статистика (сьогодні, тиждень, всього, рейтинг)
- Календар-розклад з підсвіткою зайнятих днів
- Список майбутніх записів
- Профіль майстра (read-only)

## 🗃️ Дані та структура

### Категорії послуг
- 💅 Манікюр (6 послуг)
- 🦶 Педикюр (4 послуги)
- 🪄 Брови (5 послуг)
- 👁️ Вії (6 послуг)
- ✂️ Стрижки та укладки (6 послуг)

### Майстри
- 4 сертифікованих майстри з фото, рейтингом, розкладом

### Зберігання даних
- **Zustand** (in-memory state) — записи, бронювання
- **localStorage** — стан авторизації
- Mock-дані в `src/data/mock.ts`

